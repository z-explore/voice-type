voice-type for Windows (portable)

1. Unzip this folder anywhere
2. Right-click Install.ps1 → Run with PowerShell
   (or: powershell -ExecutionPolicy Bypass -File .\Install.ps1)
3. Allow microphone if prompted
4. Press Right Alt once to talk, again to insert text

This zip contains only Windows files (exe + model + config). No Linux scripts.

Logs: %LOCALAPPDATA%\voice-type\voice-type.log
