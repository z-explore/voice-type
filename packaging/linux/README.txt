voice-type for Linux (Ubuntu 22.04 / 24.04 portable)

1. 解压本目录到任意位置
2. 运行:  bash install.sh
3. 注销并重新登录一次（input 组权限）
4. 启动：应用菜单搜「voice-type」，或终端执行 voice-type
5. 右 Alt 按一下开始说话，再按一下结束并输入文字

退出后再开：同样用应用菜单或终端命令 voice-type（不必再进解压目录）。

本压缩包只含 Linux 文件（二进制 + 模型 + 配置），不含 Windows 脚本。
系统依赖由 install.sh 用 apt 安装（麦克风库、剪贴板、ydotool 等）。
